Keeps the index fresh without the repeated full rescans, and fixes launching
Zest through the Homebrew `zest` symlink.

## Indexing

- Ordinary file changes now rebuild the index **incrementally**: only the
  directories FSEvents reported are relisted and spliced into the previous
  index. About 1.5 s on a 4M-entry index, against a 17 s / 60 CPU-second full
  walk before. Explicit reindex requests, dropped events, failures, and a daily
  safety pass still walk the whole tree.
- Full scans build faster and use less memory (1.9 → 1.6 s build, 1.80 → 1.59 GB
  peak) and the sidebar's extension breakdown got cheaper (63.6 → 49.9 ms on a
  subtree).

## Indexer setup and status

- Dismissing the Full Disk Access window during **Set Up Indexer…** no longer
  leaves background indexing switched off; it resumes the indexer it stopped.
- A registered agent that cannot launch now reports **Indexer: Failed to Start**
  with a Restart action, instead of waiting forever on "Waiting to Start".
- Adds **Index > Show Index in Finder**.
- Launching through a symlink (how Homebrew exposes `zest`) made macOS resolve
  the wrong bundle: the version printed `0.0.0-dev` and the background service
  and bundled helpers were not found. Zest now re-execs through the real path.

## Terminal commands

- `zest`, `zest-query`, and `zest-indexer` all accept `--help` and `--version`,
  report usage errors on stderr with exit code 2, and print the same version.
- `zest PATH` opens a window in that folder (`zest .`, `zest ~/Downloads`);
  each invocation is its own process.

## Fixes

- `!size:` and `!date:` qualifiers applied the filter **un-negated**. They are
  now treated as ordinary search text, matching the other unknown qualifiers.
  `!kind:`, `!ext:`, `!cat:`, and `!path:` negation is unchanged.
- Uninstalling reports failure truthfully instead of always claiming success,
  and lets a later reinstall offer setup again.

## Install or update

Download `zest-universal-apple-darwin.pkg` and install it, then open Zest from
Applications. The Universal app and installer are Developer ID signed, notarized,
and stapled. Requires macOS 14 or newer.

Homebrew:

```sh
brew update
brew upgrade --cask zest
```

For a first installation, use `brew install --cask helgesverre/tap/zest`.
Homebrew exposes `zest`, `zest-query`, and `zest-indexer` on PATH.

Stop background indexing from the Index menu before upgrading if it is running.
The index format is unchanged from 0.1.1, so your existing index, pins, and
preferences are kept and no rescan is required.

This remains a beta. Full Disk Access and background-item approval are separate
permissions; skipping access setup limits coverage. The broader clean-account,
physical Intel, and long-running daemon acceptance work remains ongoing.
