Fixes indexer setup getting stuck at **“Status Unavailable”** after a fresh install or reinstall.

- Offers **Index > Set Up Indexer…** when macOS has no background registration record and the bundled helper is valid.
- Avoids unregistering a service that has not been registered.
- Adds **Show Status Error…** for genuine failures instead of hiding the underlying error.
- Adds a read-only `zest --indexer-status` diagnostic and packaged-service regression checks for Apple Silicon and Intel.

## Install or update

Download `zest-universal-apple-darwin.pkg` and install it, then open Zest from Applications.
The Universal app and installer are Developer ID signed, notarized, and stapled. Requires macOS 14 or newer.

Homebrew:

```sh
brew update
brew upgrade --cask zest
```

For a first installation, use `brew install --cask helgesverre/tap/zest`.
Homebrew exposes `zest`, `zest-query`, and `zest-indexer` on PATH.

Stop background indexing from the Index menu before upgrading if it is running.
Your index and preferences are retained. Open **Index > Set Up Indexer…** afterward
if setup is offered; installation does not start indexing or grant permissions automatically.

This remains a beta. Full Disk Access and background-item approval are separate
permissions; skipping access setup limits coverage. The broader clean-account,
physical Intel, and long-running daemon acceptance work remains ongoing.
