# Zest 0.1.0 — initial beta

A fast native macOS file browser backed by a local background index.

- Universal build for Apple Silicon and Intel, macOS 14 or newer.
- Developer ID signed app and installer, notarized and stapled by Apple.
- Guided Full Disk Access setup, initial indexing progress, and indexer controls.
- Local filename search, filters, previews, and automatic index refresh.

## Install

Download `zest-universal-apple-darwin.pkg`, install, then open Zest from Applications.
Choose **Index > Set Up Indexer** when ready to scan. Installation does not start
the daemon or grant permissions automatically.

Homebrew (once the tap update is published):

```sh
brew install --cask helgesverre/tap/zest
```

The package contains the signed `Zest.app`; no separate app archive is required.
`zest-query` is exposed by the Homebrew cask. There is no automatic app updater.

## Beta limitations

- Full Disk Access and macOS background-item approval are separate permissions.
  Skipping access setup limits coverage; the UI does not yet summarize all denied
  locations. File previews may require separate permission for the app.
- Clean-account permission flows, physical Intel hardware, and upgrades while
  indexing have not completed the full acceptance matrix. Intel executables were
  tested through Rosetta, including packaged scan/query and UI rendering.
- Disable background indexing from the Index menu before upgrading or removing
  the app. Index and preferences are retained. Remove obsolete Full Disk Access
  entries yourself in System Settings.
- Large-library, multi-day resource use is still being evaluated.

Please report problems with your macOS version, architecture, and reproduction
steps. Do not attach private file lists or index databases to public issues.
